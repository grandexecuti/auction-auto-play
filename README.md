# auction-auto-play

基于 **ADB + OCR** 的 Windows 自动化脚本，用于在 900×1600 分辨率下自动完成拍卖类手游的一整局流程：进大厅、选房、开局、读预估价、出价、结算、领补偿、再来一局。

> 本项目只使用截屏、点击和本机 OCR，不读取或修改游戏内存、不抓包、不修改游戏文件。

## 功能

- 自动从大厅进入排位赛，并在选房地图上选择指定房间
- OCR 读取「当前预估最低价格」，按 `预估价 × AGGR - OFFSET` 出价，并可设置单局硬上限 `MAX_BID`
- 自动处理匹配、抽地图、回合结算、失败补偿、再来一局
- 仓库满时自动进入回收界面，快速回收高品质藏品换金币并腾出仓库格
- 掉线弹窗自动确认重连，登录页自动进入游戏
- 全程日志输出到 `auto_play.log`，可用 `DRY=1` 只打印不点击

## 环境要求

| 依赖 | 说明 |
| --- | --- |
| Windows 10 / 11 | 使用系统自带的 `Windows.Media.Ocr`，无需安装 OCR 引擎 |
| Python 3.9+ | 依赖 `Pillow` |
| adb | 雷电模拟器等模拟器自带，或将 adb 加入 PATH |
| 模拟器 | 游戏窗口分辨率 **900×1600**（脚本内坐标按此分辨率标定） |

```bat
pip install pillow
```

## 快速开始

```bat
set ADB=E:\leidian\LDPlayer14\adb.exe
set SERIAL=127.0.0.1:5555
python auto_play.py
```

常用激进/保守配置：

```bat
rem 保守：出价 = 预估价 - 1000，单局最高 5000
set AGGR=1.0
set OFFSET=1000
set MAX_BID=5000
python auto_play.py

rem 激进：出价 = 预估价 x 1.2，单局最高 12000
set AGGR=1.2
set OFFSET=0
set MAX_BID=12000
python auto_play.py
```

## 配置项（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `ADB` | `adb` | adb 可执行文件路径 |
| `SERIAL` | `127.0.0.1:5555` | 模拟器 adb 地址 |
| `AGGR` | `1.0` | 出价倍率，出价 = `预估价 × AGGR - OFFSET` |
| `OFFSET` | `1000` | 出价减免额 |
| `MAX_BID` | `5000` | 单局出价硬上限（0 表示不限制） |
| `MATCHES` | `0` | 目标场次，`0` 表示无限循环 |
| `DRY` | `0` | `1` 时只打印点击位置，不实际操作 |

## 工作流程

```
大厅 → 排位赛 → 选房地图 → 开始行动
   → 读预估价 → 开键盘 → 输入出价 → 提交
   → 匹配/抽地图 → 回合结算 → 跳过动画
   → 领补偿（若有）→ 再来一局 → 循环
```

出价界面的判定依赖底部按钮文字（`工具 / 出价 / 托管`），只在确认处于出价界面时才读取预估价，避免把大厅里的「资产要求」误识别成价格。

## 已知限制

- 屏幕坐标按 900×1600 标定，其他分辨率需要自行调整常量
- 依赖游戏当前的中文 UI 文案（如「开始行动」「出价」「领取补偿」），游戏改版后可能需要更新匹配词
- OCR 有延迟，回合剩余时间很短时可能错过一次出价；程序会在下一个预估价变化时重试
